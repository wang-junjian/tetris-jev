AI 接口文档 — window.TetrisAPI

引擎与渲染分离，外部智能体（Playwright / Puppeteer / harness 插件）可直接驱动：

方法说明
getState()结构化状态：棋盘矩阵、当前方块、next、分数等
getStateText()对 LLM 友好的文本序列化
getPlacements()当前方块的全部合法落点及文字化结果描述（可直接作为 Choice criteria）
executePlacement(p)把方块旋转/平移到落点 {rot, x} 并硬降锁定
applyAction(a)执行 left / right / rotate / rotate_ccw / soft_drop / hard_drop
onEvent(cb)订阅 lock / gameover / lineclear
setGravity(b)开关重力（AI 模式建议关闭）
reset() / start()重开 / 开始
// Playwright 外部驱动示例
const page = await browser.newPage();
await page.goto('file:///path/to/index.html');
await page.evaluate(() => TetrisAPI.start());
while (!(await page.evaluate(() => TetrisAPI.getState().gameOver))) {
  const placements = await page.evaluate(() => TetrisAPI.getPlacements());
  const act = await myAgent.decide(placements);   // 你的 Jev/LLM 决策
  await page.evaluate(p => TetrisAPI.executePlacement(p), act);
}
设计参考 trungdq88/jev-tetris（Jev 官方生态验证过的玩法）：代码枚举全部合法落点并模拟结果，把数字转成文字（Jev 读文本强于算术），一个请求并行携带 placement Choice + strategy/board_health/next_piece_fits 投机问题；「判断链」（先 strategy 后落点两跳）为实验开关，已验证为回退，仅作对照。官方 API 不允许浏览器直连（CORS 白名单），先运行 node jev-proxy.mjs 8787。
